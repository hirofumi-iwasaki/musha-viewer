# musha-viewer：プロジェクト方針

策定日：2026-11-01。状態：画像プレビューと簡易EXIF表示を実装。C2PA検証・設定保存・ドラッグ＆ドロップを初版へ追加し、macOS実機検証はユーザーが行う。

## 目的

画像・動画をプレビューし、ファイルのメタデータとC2PA情報を同じ画面で確認できる閲覧専用アプリを作る。メタデータを確認する一般ユーザーと、来歴や技術情報を調べるユーザーを対象とする。0.1.0は画像を対象とし、動画は後続リリースへ延期する。

## 確定した方針

- 仮称・リポジトリ名は `musha-viewer`。
- 全対象OSでDart＋Flutterをアプリケーションの基盤にする。
- 初版はmacOS 27を対象とし、将来Windows、Ubuntu、iOS、iPadOS、Androidへ展開する。
- メイン領域に画像または動画を表示する。
- 右側に幅変更・開閉可能なインスペクターを設け、キーと値を縦に並ぶ2列の一覧で表示する。
- プレビュー、メタデータ抽出、C2PA検証は独立して動作させる。
- ウィンドウなどの設定をOS推奨の場所に保存する。
- GitHubでオープンソース公開し、独自成果物にApache License 2.0を適用する。
- 将来のApp Store配布を見据え、macOSでは初期からSandbox内で検証する。

## 初版の範囲

| 領域 | 機能 |
| --- | --- |
| 入力 | ファイル選択、ドラッグ＆ドロップ |
| 画像 | 表示、拡大縮小、ウィンドウに合わせる、等倍表示 |
| 動画 | 初版では未対応。後続で再生、一時停止、シーク、音量、時間表示を実装 |
| メタデータ | キー・値の一覧、検索、選択・コピー、長い値と生データの詳細確認 |
| C2PA | 検出、内容・署名の検証、信頼状態、詳細と未検証理由の表示 |
| 設定 | ウィンドウサイズ・位置、最大化状態、ペイン幅・開閉、テーマ |

初版の基本単位は1ウィンドウで1ファイルの閲覧とする。動画、Finderの「このアプリケーションで開く」、画像変換、メタデータ編集、署名追加・削除、バッチ処理、複数ウィンドウは初版の対象外。開いた元ファイルは変更しない。画像・メタデータの対応範囲は実装と試験結果に応じて明記し、全タグの網羅を公開条件にしない。

## 画面方針

上部にファイルを開く操作とファイル名を置き、中央のプレビューと右インスペクターを分割する。右上にC2PAの要約・詳細への入口、続いて検索とメタデータ一覧を配置する。下部にファイル概要と解析状況・警告を表示する。

長い値は折り返しと詳細ビューで確認できるようにする。配列・トラックなどの所属をキーパスに残し、同名項目を消さない。行は仮想化し、大量の項目でもUIを停止させない。キーボード操作、VoiceOver、文字サイズ変更を考慮する。

iPadOSでは利用可能な幅に応じて右ペインを使い、狭い画面ではシートまたは別画面へ切り替える。切り替え幅と最小ウィンドウサイズは試作で決める。

## 未確定事項

プレビュー・解析器の対応形式、macOSの対応CPU、依存パッケージとバージョン、Bundle ID、信頼リストの供給元は検証後に確定する。初版の対応を実装前に保証しない。Windowsなどの具体的な最低OSバージョンは各移植の着手時に決定する。
