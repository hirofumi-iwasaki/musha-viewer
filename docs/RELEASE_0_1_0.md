# 0.1.0 公開判定とmacOS実機検証

作業ブランチは `release/0.1.0`。画像表示、簡易メタデータ、C2PA検証、設定保存、ドラッグ＆ドロップを初版の対象とする。動画とFinder関連付けは後続へ延期する。

この文書のチェック欄は、コードの存在やLinuxでの試験だけでは完了にしない。macOSの実機検証はユーザーが担当し、確認したOS、CPU、Flutter、Xcode、Rustのバージョンを記録する。

## macOSで確認すること

- [ ] ネイティブC2PAライブラリを含めてビルドし、生成したアプリを直接起動できる。
- [ ] ファイル選択とFinderからのドラッグ＆ドロップでJPEG・PNGを表示できる。日本語・空白を含むパスと外付けディスクも確認する。
- [ ] C2PA付きの正常画像で検証結果・詳細が表示される。改変済みファイルでは整合性不一致が表示され、署名者の信頼状態と混同しない。
- [ ] C2PA未検出、未対応形式、破損、ライブラリ読込失敗の表示を区別できる。検証失敗でも画像や取得済みメタデータを確認できる。
- [ ] ネットワークを使用せず検証でき、取得できない外部参照を検証済みと表示しない。
- [ ] リサイズ、移動、最大化、右ペイン変更、テーマ変更が再起動後に復元される。
- [ ] 画面構成の変更後もウィンドウへアクセスできる。壊れた設定ファイルで起動が妨げられない。
- [ ] 素早いファイル切り替えと終了で古い結果が混入せず、元ファイルの内容が変化しない。

## 公開前に確認すること

- [ ] 対応形式、制限、未検証項目、実機で見つかった既知の問題をREADMEと実装記録に反映する。
- [ ] Bundle ID、署名・公証、配布物へ含めるネイティブライブラリと第三者通知を確認する。
- [ ] GitHubから取得した配布物が、開発ツールなしで起動し、C2PA検証を実行できる。
- [ ] 合格したコミットへ `v0.1.0` タグを付け、検証済み成果物をGitHub Releaseへ添付する。

ビルド・検証結果は[実装記録](IMPLEMENTATION_0_1_0.md)に記録する。署名成功は画像内容の真実性を保証せず、C2PA未検出も改ざんの証拠として扱わない。
